# 식수체크 시스템 (PoC)

ATEC 시그니처 컬러 기반의 사내 점심/저녁 예약 시스템입니다.  
Python + Streamlit + SQLite로 구성되어, 별도 DB 서버 없이 실행합니다.

## 실행 방법

```powershell
cd "프로젝트 폴더"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python init_db.py
python -m streamlit run app.py
```

- 로컬: http://localhost:8501
- 사내 서버: `python -m streamlit run app.py --server.address 0.0.0.0 --server.port 8501`

## 인터넷 배포 (Render)

휴대폰·집에서도 접속하려면 Render 유료(Starter) 서비스로 올립니다. 데이터베이스는 `/var/data/siksu.db` 고정 디스크에 저장되어 재배포 후에도 남습니다.

1. GitHub에 이 폴더를 올립니다. (`data/*.db`는 올리지 않습니다.)
2. [Render](https://render.com)에서 New → Blueprint를 고르고 저장소를 연결합니다. `render.yaml`이 서비스·디스크·실행 명령을 만듭니다.
3. 환경변수 `SIKSU_ADMIN_PASSWORD`를 관리자 비밀번호로 넣습니다.
4. 배포가 끝나면 `https://atec-siksu.onrender.com` 형태의 주소가 나옵니다.
5. 기존 로컬 데이터가 필요하면 `data/siksu.db`를 서버 `/var/data/siksu.db`로 복사합니다.

무료 플랜은 잠시 뒤 잠들기 때문에 24시간 접속에는 Starter가 필요합니다.

## 로그인

- **계열사**: 에이텍컴퓨터 / 에이텍모빌리티 / 에이텍오토
- **아이디**: 직원 이름 (예: `황태연`)
- **초기 비밀번호**: `1111`
- 첫 로그인 후 비밀번호 변경 안내가 뜹니다. `1111`은 다시 쓸 수 없습니다.
- **아이디 저장** / **자동 로그인**을 체크하면 해당 브라우저에서 다시 아이디를 치거나 로그인할 필요가 없습니다.
- 식당 바코드 전용 계정은 로그인 화면에 따로 보이지 않습니다. 화면 아래 저작권 문구를 5번 누르면 식당 화면으로 들어갈 수 있습니다. (계열사 `에이텍모빌리티` / 아이디 `식당` / 비밀번호 `1111`)

샘플 직원 18명이 들어 있습니다. 황태연은 에이텍컴퓨터입니다. 실제 명단은 프로젝트 폴더에 `인원명단.xlsx`(이름, 부서, 계열사)를 넣으면 불러옵니다. 공무팀 계정은 내 정보에서 관리자 대시보드로 바로 들어갈 수 있습니다.

## 화면 구성

하단 메뉴 4개입니다.

1. **홈** – 오늘 점심/저녁 O·X 예약, 예약 인원, 오늘 식단(텍스트)
2. **식단표** – 월~금 주간 식단, 점심/저녁 전환 (메뉴 사진 없음)
3. **자동예약** – 켜고 끄기, 요일별 점심/저녁 패턴, 예약 전 알림 설정
4. **QR코드** – 식당 리더기용 개인 QR. 스캔하면 실식수로 기록됩니다.
5. **내 정보** – 비밀번호 변경, 로그아웃, 관리자 대시보드

## 비즈니스 규칙

- 점심 마감 08:40 / 저녁 마감 13:40 (Asia/Seoul)
- 마감된 항목은 O/X가 잠기고 "마감되었습니다"가 표시됩니다.
- 자동예약이 켜져 있으면 해당 요일 기본값이 신청값으로 반영됩니다.
- 자동예약이 없고 마감까지 제출하지 않으면 **안 먹음**으로 집계됩니다.

## 관리자

- 공무팀 계정: 내 정보 → 관리자 대시보드
- 그 외: 내 정보에서 관리자 비밀번호 입력 (기본 `admin1234`, 환경변수 `SIKSU_ADMIN_PASSWORD`)
- 날짜별 인원, 부서 집계, 엑셀 다운로드
- 주간 식단표 엑셀 업로드(중식/석식 양식)
- 인원 명단 조회, 한 명 추가/삭제 (`인원명단.xlsx`를 폴더에 두면 초기 적재)
- 개인 QR 체크인, 노쇼 집계, 실식수 엑셀 다운로드

## 식당 바코드 화면

- 직원 메뉴(홈/식단표/자동예약/QR/내정보)는 보이지 않습니다.
- 월~금 요일을 고르면 점심(12:00–13:30), 석식(17:00–18:00)에 찍힌 사람 목록이 나옵니다.
- USB 바코드 리더기로 찍으면 Enter와 함께 즉시 체크인되고, 목록은 1초마다 갱신됩니다.
- 점심/석식 시간이 아니면 스캔이 기록되지 않습니다.
